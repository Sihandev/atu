# Drop hasil export Stitch di folder ini

Simpan dengan nama persis seperti ini (biar gue tau mana halaman apa):

```
design/stitch/
  beranda.html       <- Beranda — Alyssa
  cek-tarif.html     <- Cek Tarif
  rute.html          <- Daftar Rute
  tracking.html      <- Lacak Kiriman
```

Kalau export-nya berupa ZIP, extract dulu di sini — struktur foldernya bebas,
yang penting file HTML/CSS-nya ada.

Kalau yang lo punya screenshot (bukan kode), simpan sebagai:

```
  beranda.png
  cek-tarif.png
  rute.png
  tracking.png
```

Screenshot ambil per-layar dalam kondisi ter-zoom penuh (bukan zoom 13% dari canvas),
biar warna dan ukuran teksnya kebaca.
